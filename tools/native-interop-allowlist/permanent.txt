# Native interop that stays in C# for good. Format and rules: tools/check-native-interop.sh.
# Lines naming ui/Prisc.Interop or its tests may name no file yet: WP-FOUNDATION creates them.

# The generated bindings (cargo codegen) are the one place DllImports live.
ui/Prisc.Interop/Generated/**                 *                     Generated by prisc_codegen from crates/prisc_interop/src/ffi; never hand-edited.

# The loader.
ui/Prisc.Interop/InteropLibrary.cs            NativeLibrary         The loader resolves, loads, checks and frees prisc_interop itself and installs the DllImport resolver.
ui/Prisc.Interop/InteropLibrary.cs            DllImport             The loader registers the DllImportResolver that points every generated import at the checked library.
ui/Prisc.Interop/InteropLibrary.cs            delegate-unmanaged    The loader reads the ABI hash through a function pointer before any generated import may resolve.
ui/Prisc.Interop/AssemblyInfo.cs              DllImport             DefaultDllImportSearchPaths for the generated imports of the one native library.
ui/Prisc.Interop/Prisc.Interop.csproj         DllImport             Project comments that explain where the generated DllImports and their resolver live.

# Callbacks the OS API is shaped around (ABI rule C3): static thunks handed to Rust.
ui/Prisc.Interop/*.cs                         UnmanagedCallersOnly  Callback thunks (log sink, audio, NSServices, foreground watch) that Rust invokes, per ABI rule C3.
ui/Prisc.Interop/*.cs                         delegate-unmanaged    Function pointers to those thunks, passed to the generated exports that take callbacks.

# Tests that inspect the native library itself.
ui/Prisc.Interop.Tests/**                     NativeLibrary         Loader tests load the library directly to check its exports and to feed the loader a fake library.
ui/Prisc.VideoSDK.Tests/GpuInteropTests.cs    Marshal               GPU tests check the COM reference counts of the device pointers the exports hand out.

# FFmpeg (FFmpeg.AutoGen bindings, a package): callbacks FFmpeg calls back into.
ui/Prisc.VideoSDK/Media/EncoderTexturePool.cs UnmanagedCallersOnly  The av_buffer free callback that returns a pooled encoder texture when FFmpeg drops the frame.
ui/Prisc.VideoSDK/Media/EncoderTexturePool.cs delegate-unmanaged    Pointer to that av_buffer free callback, stored in the FFmpeg buffer.
ui/Prisc.VideoSDK/Media/Nv12Converter.cs      UnmanagedCallersOnly  The no-op av_buffer free callback for NV12 textures the converter keeps owning.
ui/Prisc.VideoSDK/Media/Nv12Converter.cs      delegate-unmanaged    Pointer to that no-op av_buffer free callback, stored in the FFmpeg buffer.
ui/Prisc.VideoSDK/Playback/VideoDecodeWorker.cs Marshal             The AVCodecContext get_format callback that picks the hardware pixel format for FFmpeg.
